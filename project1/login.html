Frequently Asked Questions

1. What is the main purpose of your project? +
My project is a House/Map Creator that helps users create a house layout based on their plot and room dimensions.
2. How does your project create the house layout? +
JavaScript takes the plot and room dimensions and automatically places the rooms inside the plot without overlapping.
3. Why did you use HTML, CSS and JavaScript? +
HTML creates the structure, CSS designs the interface, and JavaScript handles the logic and layout.
4. How do you check that rooms don't exceed the plot area? +
I calculate the total area of all rooms and compare it with the plot area. If it exceeds the plot area, the room is not added.
5. How does generateFloorPlan() work? +
It converts the plot and room dimensions into pixels and creates room boxes inside the plot using JavaScript.
6. How do you prevent rooms from overlapping? +
I use a collision-checking function that compares the position and size of each room with existing rooms.
7. How are you saving the house design? +
Currently, I use localStorage to save the plot and room information in the browser.
8. What features would you add in the future? +
I would add user accounts, MongoDB database storage, draggable and resizable rooms, doors, windows, and multiple saved house designs.
